# Ilakkiya M C — Personal Portfolio

A modern, single-file portfolio website built with HTML, CSS, and Vanilla JS.

## 📁 File Structure
```
ilakkiya-portfolio/
└── index.html          # Complete portfolio (all CSS & JS inline)
```

## 🚀 Quick Start (Local)
1. Place `index.html` in a folder.
2. Add your `Ilakkiyaresume.pdf` in the same folder (for the download button).
3. Open `index.html` in any browser — no build step needed.

## 🌐 Deploy to GitHub Pages (Free)
1. Create a new GitHub repository (e.g. `ilakkiya-portfolio`).
2. Upload `index.html` (and your resume PDF).
3. Go to **Settings → Pages → Source → main branch → / (root)**.
4. Your site will be live at `https://<username>.github.io/ilakkiya-portfolio`.

## ▲ Deploy to Vercel (Free, Custom Domain)
1. Push files to a GitHub repo.
2. Visit [vercel.com](https://vercel.com) → **New Project** → import your repo.
3. Framework: **Other** · Root: `/` · No build command needed.
4. Click **Deploy**. Live in ~30 seconds.

## 🔺 Deploy to Netlify (Free)
1. Drag and drop the `ilakkiya-portfolio` folder onto [app.netlify.com/drop](https://app.netlify.com/drop).
2. Done — you get a `*.netlify.app` URL instantly.

## ✏️ Customization
- **Colors:** Edit CSS variables in `:root { ... }` near the top of the `<style>` block.
- **Content:** All text is in the HTML — search for any section heading and update directly.
- **Resume link:** Replace `Ilakkiyaresume.pdf` with your actual PDF filename.
- **LinkedIn / GitHub URLs:** Update the `href` values in the Contact section and nav logo.
